# Trademark Risk Note

Status: Stage 4 draft  
Date: 2026-06-04  

QuantumBridge is an independent project. This note addresses trademark and endorsement risk.

## 1. Naming restrictions

- Do not use Qiskit or PennyLane as the QuantumBridge project name.
- Do not use IBM or Xanadu names in a way that suggests sponsorship, certification, or endorsement.
- Do not use upstream logos or visual identity without explicit permission.

## 2. Acceptable factual language

Allowed:

- "compatible with common Qiskit workflows"
- "provides optional Qiskit adapters"
- "provides optional PennyLane adapters"
- "inspired by common quantum computing workflows"

Avoid:

- "official Qiskit version"
- "official PennyLane version"
- "IBM-backed"
- "Xanadu-backed"
- "drop-in replacement" unless validated and legally reviewed.

## 3. Recommended public description

Use:

> QuantumBridge is an independent quantum SDK that provides adapters and compatibility layers for common quantum computing workflows.

## 4. Commercial release note

Commercial marketing materials require legal review before publication.
