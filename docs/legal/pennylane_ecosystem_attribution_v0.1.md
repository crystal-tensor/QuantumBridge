# PennyLane Ecosystem Attribution v0.1

Status: Stage 7 planning  

QuantumBridge may optionally depend on PennyLane and PennyLane ecosystem plugins. PennyLane remains an independent upstream project with its own maintainers, license, trademarks, release schedule, and support policy.

QuantumBridge Stage 7 does not vendor PennyLane packages and does not copy PennyLane source, tests, documentation, comments, or error messages. Adapter files use runtime imports, public object names, and independently written schema wrappers.

Use of PennyLane package names is for compatibility, dependency, and attribution purposes only. QuantumBridge is not endorsed by Xanadu or the PennyLane project.

Any future source port must be explicitly reviewed and recorded before merging.

Stage 7.2 adds a `PennyLaneResult` schema wrapper and broader runtime public-name inventory. This remains interoperability metadata and does not claim complete PennyLane API, device, plugin, interface, qchem, or transform compatibility.
