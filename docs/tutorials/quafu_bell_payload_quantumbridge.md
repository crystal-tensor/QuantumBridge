# Quafu-Compatible Bell Payload With QuantumBridge

Run:

```bash
python3 examples/quafu_bell_payload_quantumbridge.py
```

The example builds a QuantumBridge Bell circuit, converts it to a clean-room
Quafu-compatible payload and job spec, and prints warnings, provenance, and the
optional pyquafu boundary. It does not access cloud, tokens, or hardware.
