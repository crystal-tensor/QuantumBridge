# QuantumBridge Industry Capability Taxonomy v1

Status: canonical architecture
Date: 2026-10-19

QuantumBridge 的最终产品能力固定按四个大类组织。Qiskit 与 Cirq 是比较和兼容生态，不是产品顶层分类。统一 IR、电路/QML、编译、算法、模拟器、Provider/Job/Result、夸父云执行、数据验证与来源审计属于跨领域共享底座。

| 大类 | 细分方向 | QuantumBridge 目标能力 | Qiskit 生态对照 | Cirq 生态对照 |
| --- | --- | --- | --- | --- |
| **科学计算** | **量子化学** | 分子哈密顿量、Hartree-Fock、UCCSD/VQE、基态与激发态、偶极矩、分子结构优化的统一工作流 | Qiskit Nature 的电子结构、分子性质、活性空间、映射和求解接口 | OpenFermion 的分子数据、费米子算子、映射和 Cirq 执行 |
| 科学计算 | **量子生物／生物医药** | 药物小分子能量与构象、蛋白局部活性空间、分子相互作用，并连接经典筛选和实验验证 | 复用 Nature 化学能力，领域流程另建 | 复用 OpenFermion 组件，生物业务流程另建 |
| 科学计算 | **量子材料** | 晶格与周期模型、能谱及能带相关计算，服务电池、催化剂、半导体和表面吸附 | Nature 的 Fermi-Hubbard、Heisenberg、Ising 等模型 | OpenFermion 材料模型并结合 Cirq 模拟 |

## 验收规则

每个细分方向必须维护以下证据，缺一项不得标记为“完成”：

1. 原生或明确标注的适配 API 清单。
2. 端到端可运行示例和自动化测试。
3. 经典基线或可解释的正确性验证。
4. 可执行到夸父云的电路部分及真实任务证据；纯经典步骤必须明确标注。
5. 能力边界、风险、非目标和来源证明。
6. 与 Qiskit/Cirq 对照时区分原生实现、上游透传和未实现项。

机器可读契约位于 `quantumbridge.ecosystem.industry_taxonomy`。
