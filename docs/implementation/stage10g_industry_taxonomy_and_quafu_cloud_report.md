## Cloud implementation

- Optional current client: `quarkstudio>=7.3.9`.
- Optional circuit/transpiler package: `quarkcircuit>=0.5.13`.
- Credentials: explicit token or `QUAFU_TOKEN` / `QUAFU_API_TOKEN`, read only on explicit cloud backend construction.
- Transport: `quark.Task` public API.
- Submission: OpenQASM 2, backend name, task name, shots, compile flag.
- Jobs: task ID, polling, queue status, cancellation, timeout and result conversion.
- Results: counts, probabilities, actual shots, backend, QASM SHA-256, warnings and provenance.
- Security: tokens are never included in job dictionaries, result schemas, logs, examples, tests or repository files.
