# QuantumBridge v0.1.0-p1-rc1

QuantumBridge v0.1.0-p1-rc1 is a P1 release candidate. It is not a production
release.

QuantumBridge is an independent experimental quantum SDK. Qiskit and PennyLane
support is provided only through optional compatibility layers for a limited
subset of workflows. This release candidate does not claim full feature parity
with Qiskit or PennyLane and does not imply endorsement by IBM, Qiskit, Xanadu,
or PennyLane.

## 2. P0 / P1 Supported Features

- Native circuit construction and supported gate subset
- Measurement and result containers
- Statevector simulator
- Shot sampler
- Pauli strings, Hamiltonian basics, and sparse operator helpers
- Parameter-shift and finite-difference gradient helpers
- Simple VQE and QAOA examples
- OpenQASM-style subset import/export
- Basic compiler PassManager and limited optimization passes
- Basic noise channel objects and noise metadata
- Lightweight provider/backend/job abstractions
- Basic QML-style tape, QNode, and template helpers

## 3. Qiskit Optional Adapter Status

Qiskit support is optional. When the `qiskit` extra is installed, the P1 subset
supports basic circuit import/export, IR bridge behavior, and counts result
adaptation for selected workflows.

This is not full Qiskit compatibility.

## 4. PennyLane Optional Adapter Status

PennyLane support is optional. When the `pennylane` extra is installed, the P1
subset supports selected observable, tape, and executable bridge workflows.

This is not full PennyLane compatibility.

## 7. Known Limitations

- Not production ready
- No full Qiskit feature parity
- No full PennyLane feature parity
- No full OpenQASM grammar parser
- No Qiskit Aer adapter
- No real noisy execution path beyond the current basic metadata/channel layer
- No hardware/cloud provider integration
- Visualization remains experimental/minimal
- Compiler support remains a limited native subset
