# QuantumBridge Studio Frontend Local Data Contract v0.1

The frontend prototype consumes local seed data generated by:

```bash
python3 examples/studio_generate_frontend_seed_data_quantumbridge.py
```

## Files

- `studio/src/data/sampleCatalog.json`
- `studio/src/data/sampleWorkflows.json`
- `studio/src/data/sampleResults.json`
- `studio/src/data/sampleBenchmarkReport.json`
- `studio/src/data/seedData.js`

## Required Fields

Catalog records include project identifiers, titles, categories, capability
levels, workflow counts, warnings, and provenance.

Workflow records include workflow identifiers, project identifiers, categories,
execution flags, local-only flags, warning counts, input schema, output schema,
and provenance.

Result records include execution identifiers, workflow identifiers, status,
result JSON, warnings, and provenance.

Export records include JSON, Markdown, Python snippet, and notebook-stub
payloads.
