# QuantumBridge Studio Frontend Security Boundary v0.1

The Stage 10D frontend prototype is intentionally constrained:

- no cloud execution
- no credential reading
- no hardware access
- no production server
- no external network endpoints
- no official endorsement claim
- no copied third-party UI, prose, source, or branding
- no committed `node_modules`, `dist`, `build`, or `coverage`

Third-party package names may appear only as compatibility identifiers in local
metadata. The UI must not use third-party logos, copied visual design systems,
or copied product copy.
