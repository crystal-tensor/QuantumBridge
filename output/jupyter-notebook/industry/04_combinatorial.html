1. 原理与计算对象¶

四个节点划入两组，跨组边权之和为割值。令 $x_i=(1-Z_i)/2$，单条边是否被割为 $(1-Z_iZ_j)/2$。所以负割值是严格二次 Ising 代价：$H_C=-\sum w_{ij}(1-Z_iZ_j)/2$。 这一例确实是二次模型，成本 Pauli 阶数应为 2。通过原生一层 QAOA 生成候选，与所有 16 个划分的完全枚举比较；互补位串表示同一个无向割。

2. 实现步骤¶

  1. 声明四节点五条带权边。
  2. 枚举割划分、计算负割代价与精确最优。
  3. 校验二次 Z 展开并优化 QAOA 参数。
  4. 采样并恢复节点分组。
  5. 报告最佳实际观测割、最优频率和成本差。

def maxcut_case():
    edges = [(0, 1, 1), (1, 2, 2), (2, 3, 1), (3, 0, 2), (0, 2, 0.5)]
    candidates = []
    for bits in labels(4):
        cut = sum(weight for a, b, weight in edges if bits[a] != bits[b])
        candidates.append(
            {
                "bitstring": bits,
                "partition0": [i for i, bit in enumerate(bits) if bit == "0"],
                "cut_weight": cut,
                "feasible": True,
                "objective": -cut,
                "penalized_cost": -cut,
            }
        )
    return optimization_case(
        "combinatorial",
        "industry",
        "Weighted four-node MaxCut",
        {
            "nodes": 4,
            "edges": edges,
            "objective": "minimize minus cut weight",
            "penalty": 0,
        },
        candidates,
    )
